# Smart Car Parking System using UDP and Dijkstra Algorithm

## Overview

This project is a real-time smart parking management system developed using Java UDP socket programming, HTML/CSS/JavaScript frontend, and Cisco Packet Tracer simulation.

The system helps multiple users find the nearest available parking slot using Dijkstra’s shortest path algorithm.

---

## Features

* UDP Client-Server Communication
* Real-Time Parking Slot Allocation
* Dijkstra Shortest Path Algorithm
* Multiple Client Support
* Interactive Frontend UI
* Cisco Packet Tracer Simulation

---

## Technologies Used

* Java
* UDP Socket Programming
* HTML
* CSS
* JavaScript
* Cisco Packet Tracer

---

## System Architecture

Clients send parking requests to a centralized parking server using UDP protocol. The server calculates the nearest available slot and sends the response back to the client.

---

## How to Run

### Server

```bash
javac ParkingServer.java
java ParkingServer
```

### Client

```bash
javac ParkingClient.java
java ParkingClient
```

Open browser:

```text
http://localhost:8080
```
